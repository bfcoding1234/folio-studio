# 每周复盘，最后只留下三个决定

## 先看实际发生了什么

把这一周的记录分成三类：已经交付的事、还在推进的事，以及临时插进来的事。不要急着评价效率，先把事实和感受分开。

> 「我觉得这一周很忙」是一种感受；「原定三件事，交付一件，另外两件都在等反馈」才是可以继续追问的事实。

## 再问哪些做法值得保留

- **继续做**：哪一种做法反复帮你节省了时间？例如，把需要别人答复的问题提前一天发出去。
- **停止做**：哪项投入没有帮助你更快做决定？例如，一遍遍同步不变的进展。
- **试一次**：哪项改动成本很低，下周就能看到结果？例如，每周二用十五分钟集中处理阻塞。

## 最后写出三个决定

| 决定 | 下周怎么验收 |
| --- | --- |
| 保留一件有效的做法 | 约定谁负责，把它放进日历 |
| 停掉一件低价值的事 | 明确从哪天起不再做，告知受影响的人 |
| 做一个小实验 | 说清楚什么时候回看、根据什么判断是否继续 |

## 把决定写成下周能做的事

比如，把「以后提早沟通」改成：「每周二上午列出本周需要别人答复的三个问题，当天发出；周五回看有几件事没有卡在等反馈。」前一句是愿望，后一句才有时间、动作和验收办法。

> 下周再打开这份复盘时，先看这三个决定，而不是从头读一遍记录。

复盘不是把上周重新写一遍，而是让下周少做一个糊涂决定。
